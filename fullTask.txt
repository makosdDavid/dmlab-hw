Energy Consumption Forecast Project
Purpose:
Forecast energy consumption based on weather data (temperature, wind, precipitation) and solar panel production/feed-in data.

Outputs:
REST API + Angular frontend (fast, visually appealing), alternative dashboard with Superset.

Architecture:
Microservice-based, Dockerized, MongoDB database.

1. Main Components
Data Collector Microservice (Python):
Fetches weather data (forecast and history) from OpenWeatherMap API and solar panel production/feed-in data (simulated or from external API such as PVOutput).
Stores all data in MongoDB.

Data Processor Microservice (Python):
Queries stored data, performs rule-based or simple statistical modeling to forecast energy consumption (e.g., based on temperature and sunlight), aggregates solar panel production and feed-in.

REST API (Python/FastAPI):
Serves processed data via endpoints for frontend and Superset.

Frontend (Angular):
Simple dashboard displaying energy consumption forecasts, current weather, and solar panel production/feed-in using charts.
Use: Angular, ngx-charts or chart.js, Angular Material.

Superset Dashboard (alternative):
Reads directly from MongoDB (via SQLAlchemy or MongoDB connector), provides visual queries and charts.

Docker Compose:
Each component runs in its own container.

2. Workflow Overview
Data Collection:

From OpenWeatherMap API: temperature, wind speed, precipitation, solar irradiance, forecast (e.g., 5-day, hourly).

Solar panel data: simulated or from external API (e.g., PVOutput), hourly production and feed-in.

Store all records in MongoDB.

Data Processing:

Energy consumption forecast using a simple rule-based model:
e.g., low temperature → increased heating demand; high temperature → increased cooling demand; high solar irradiance → increased solar production.

Aggregate solar production and feed-in.

Store or expose results for API/frontend.

Publication:

REST API endpoints:

/forecast (forecasted energy consumption, weather, solar data)

/history (historical data)

/summary (aggregated statistics)

Angular frontend:

Charts: energy consumption forecast, weather parameters, solar production/feed-in.

Time range selection, basic filtering.

Superset:

Simple dashboard with prebuilt visualizations.
