# Energy Consumption Forecast Application

## Overview
This application forecasts energy consumption based on weather data and solar panel production. It provides specialized predictions for engineers, insurance companies, and tourists to help with decision making based on energy and weather data.

## What Users See

### Main Dashboard
- **City Selection**: Users can select from a list of European cities to view localized data
- **Current Weather**: Real-time weather data including temperature, humidity, wind speed
- **Solar Production**: Current solar panel data including energy production, efficiency, panel temperature
- **Energy Consumption Forecast**: Interactive chart showing predicted consumption, production, and net consumption
- **Forecast Accuracy**: Historical accuracy of forecasts for different time periods (day, week, month, year)
- **Energy Statistics**: Key metrics including daily average consumption, monthly savings, efficiency trends, CO2 reduction

### Main Feature: Specialized Predictions
Users can access specialized predictions for different stakeholders through dedicated views:

1. **Engineer Predictions** (PRIMARY FEATURE)
   - Panel Efficiency metrics
   - Maintenance recommendations
   - Optimization suggestions
   - Performance ratio analytics
   - Expected lifespan calculations

2. **Insurance Company Predictions**
   - Risk assessment based on weather patterns
   - Claim probability calculations
   - Estimated damage costs
   - Extreme weather probability forecasts
   - Recommended coverage adjustments

3. **Tourist Predictions**
   - Optimal visiting periods for different locations
   - Comfort index ratings
   - Clear sky hours forecasts
   - Precipitation probabilities
   - Travel recommendations

## How to Use
1. Select a city from the dropdown menu
2. View current weather and solar production data
3. Check the energy consumption forecast chart
4. Access the specialized predictions (Engineer, Insurance, Tourist) through the tabs
5. Use the "Refresh Data" button to get the latest information
6. Click "View Detailed Predictions" for more comprehensive information on each stakeholder type

## Data Sources
- Weather data: OpenWeatherMap API
- Solar panel data: Simulated based on weather conditions
- Energy consumption: Calculated based on weather and historical patterns
