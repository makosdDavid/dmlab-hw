# Energy Consumption Forecast Project: Teaching Plan

## Project Overview
This teaching plan outlines a structured approach to building an Energy Consumption Forecast system using Python microservices, MongoDB, Docker, and Angular. The plan is designed for Python beginners and intermediate Angular developers.

## Learning Objectives
By the end of this project, you will be able to:
1. Build Python microservices for data collection and processing
2. Work with REST APIs (both consuming and creating)
3. Implement MongoDB for data storage
4. Create forecasting models for energy consumption
5. Containerize applications with Docker
6. Develop a modern Angular dashboard with interactive charts

## Teaching Approach
- **Project-Based Learning**: Learn by building actual components
- **Progressive Complexity**: Start simple, gradually add features
- **Hands-On Practice**: Code along with examples
- **Regular Testing**: Validate each component works before proceeding
- **Visual Feedback**: See results quickly to maintain engagement

## Detailed Technical Components

### Data Models
```python
# Weather Data Model
{
  "_id": ObjectId("..."),
  "datetime": ISODate("2024-05-05T14:00:00Z"),
  "temperature": 21.5,
  "wind_speed": 4.2,
  "precipitation": 0.0,
  "solar_irradiance": 680
}

# Solar Panel Data Model
{
  "_id": ObjectId("..."),
  "datetime": ISODate("2024-05-05T14:00:00Z"),
  "production": 5.2,
  "feed_in": 2.1
}

# Energy Forecast Model
{
  "_id": ObjectId("..."),
  "datetime": ISODate("2024-05-05T14:00:00Z"),
  "predicted_consumption": 42.0,
  "actual_consumption": 40.5,
  "solar_production": 5.2,
  "feed_in": 2.1
}
```

### Key Python Libraries to Cover
- `requests`: For API interactions
- `fastapi`: For building the REST API
- `pymongo`: For MongoDB operations
- `pandas`: For data manipulation
- `skforecast`: For time series forecasting
- `matplotlib/seaborn`: For data visualization in Python
- `pydantic`: For data validation
- `python-dotenv`: For environment management

### Key Angular Concepts to Cover
- Angular 19 control flow (@if, @for, @switch)
- Signal-based reactivity
- Lazy loading with @defer
- HttpClient for API communication
- Angular Material components
- Chart integration (ngx-charts or chart.js)
- Responsive design techniques
